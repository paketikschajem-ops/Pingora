# Pingora

Modern Flask messenger demo with responsive dark UI, demo chats, search, new chats, message sending, emoji, typing indicator and status UI.

## Run
```bash
pip install -r requirements.txt
python app.py
```

Open http://127.0.0.1:5000 locally. On Android/Pydroid 3 use the same command and open the displayed local address.

Messages are stored in memory for this demo and reset when Flask restarts.
